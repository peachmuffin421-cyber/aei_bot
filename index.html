The ÆI Seed Mini App lives in the frontend repo. This backend page is a diagnostic surface only — it is not the TWA. To launch the actual Mini App, open it from Telegram via the bot's menu button, or visit the GitHub Pages URL with ?backend=<this-origin>/ appended.

Substrate: the bridge binds directly on Heroku's $PORT. The Heroku router terminates TLS at the edge and forwards https://<app>.herokuapp.com/ to the dyno. No Cloudflare Tunnel is spawned on a web dyno. The worker.js relay is a stateless fetch proxy; all crawl logic (frontier, visited set, depth limits, hash lifting to exact Fraction, seed injection) lives in app.py. The seed loop consumes each crawled document's SHA-256 content hash (lifted to exact Fraction) as the next symbolic input x.
